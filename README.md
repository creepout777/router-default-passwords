# A-quick-way-to-find-the-local-router-s-default-password
# (⚠️ this is for educational purposes only ⚠️)

-Today, i have found an interesting way to access several routers.

So while reading through the university course of networking, i found the following command *arp -a* which shows my ARP table, and by searching a little i found out that every MAC address is prefixed by 3 hexadecimal's identifying the Company of the machine.

Searching https://maclookup.app/macaddress/a86e4e and found that it is a Huawei Device registered at the 06 October 2020, so again i went and looked for the Huawei model that has been created at this exact date and it's the HUAWEI WiFi AX3, useless information but interesting.

So lastly i seached for the Huawei default passwords https://forum.huawei.com/enterprise/intl/en/thread/huawei-router-default-login-password/667247379407060992?blogId=667247379407060992 tested them one by one at the gateway address and it actually logged me in.

Always change the default passwords of your wifi, and stay safe!!
